# Contributing

Featured Image is maintained by a single author. Pull requests from outside contributors are not accepted. Ideas are
welcome as feature requests through GitHub issues.

## Bug Reports

Search the [existing issues](https://github.com/johansan/obsidian-featured-image/issues) before
[opening a new issue](https://github.com/johansan/obsidian-featured-image/issues/new). Include the Obsidian version,
plugin version, operating system, reproduction steps, relevant plugin settings, and any sample note content or console
output needed to reproduce the problem. Remove private vault data before posting.

## Feature Requests

Search the [existing issues](https://github.com/johansan/obsidian-featured-image/issues) before
[opening a feature request](https://github.com/johansan/obsidian-featured-image/issues/new). Describe the use case and
the behavior you would like to see.

## Questions And Feedback

General questions and feedback are welcome through
[GitHub issues](https://github.com/johansan/obsidian-featured-image/issues).

## Pull Requests

Pull requests are not accepted and will be closed without review.

Featured Image is maintained by a single developer. Bug reports and feature requests through GitHub issues are the
supported way to influence the project.
